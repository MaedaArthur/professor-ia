# Prompts prontos

Prompts para copiar e colar. Cada arquivo tem uma linha explicando o uso e depois
o prompt num bloco de código, para você copiar inteiro sem levar o texto
explicativo junto.

| arquivo | quando usar |
|---|---|
| `01-estudo-guiado.md` | quando você for estudar com uma IA qualquer (ChatGPT, Claude, Gemini) e quiser que ela estude COM você em vez de despejar texto pronto |
| `02-meu-perfil.md` | uma vez, no começo: preencha seu perfil de aprendizado e cole junto do prompt 1 (e use também como seu `perfil.md` do professor) |
| `03-plano-antes-do-codigo.md` | na hora de mandar o OpenCode construir o `professor.py`, antes de deixar ele escrever qualquer linha |
| `04-handoff.md` | quando a sessão ficou longa, a IA começou a esquecer coisas ou a errar mais, e você quer abrir uma sessão nova sem perder o estado |
| `05-testar-o-professor.md` | depois que o `professor.py` roda: os testes que provam que ele atende o SPEC, incluindo as tentativas de furar as regras |

Ordem sugerida na prática: 02 (preenche o perfil), 01 (estuda), 03 (constrói),
05 (testa), 04 (quando a sessão esticar).
